Comment ça marche

Trois étapes simples, sans compte bancaire ni carte de crédit.

1

Choisissez votre carte

Sélectionnez la marque et le montant parmi les valeurs proposées.

2

Réglez votre commande

Vous recevez une adresse de paiement dédiée. Le montant exact vous est indiqué avant de valider.

3

Recevez votre code

Dès que le paiement est confirmé, votre code cadeau s'affiche à l'écran et vous est envoyé par email.

Pourquoi nous faire confiance

On sait qu'un paiement en ligne peut inquiéter la première fois. Voici comment on vous protège.

⛓

Paiement vérifié en temps réel

Chaque transaction est suivie en direct. Vous voyez la confirmation apparaître, sans rien avoir à faire.

🔒

Aucune information bancaire

On ne vous demande jamais de numéro de carte ni d'accès à votre compte. Seule une adresse de paiement dédiée est utilisée.

⚡

Livraison automatique

Le code cadeau est généré et transmis dès la confirmation du paiement, sans intervention manuelle qui pourrait retarder l'envoi.

💬

Un support qui répond

En cas de souci — mauvais montant, retard de confirmation — notre équipe vous accompagne jusqu'à la résolution.

Cartes cadeaux disponibles

Mêmes montants pour toutes les marques : 200 €, 500 € ou 1000 €.
